投資の計算ツール

投資の判断でよく出てくる計算を、数字を入れるだけで確かめられる無料ツールです。結果は前提に基づく目安です。

  • 株価の下落率・回復率計算ツール
    株価が何%下がったら、元に戻るには何%の上昇が必要かを計算できる無料ツールです。高値と現在値から下落率を出し、回復に必要な上昇率と下落率別の早見表を表示します。
  • 配当利回り計算ツール(税引前・税引後・優待込み)
    株価と1株あたり配当金から配当利回りを計算する無料ツールです。特定口座(税率20.315%)とNISAの税引後の受取額、株主優待を含めた総合利回りも計算できます。
  • クレカ積立のポイント計算ツール(年会費の損益分岐つき)
    クレカ積立の毎月の積立額と還元率から、もらえるポイントの目安を計算する無料ツールです。年会費を入れると実質の還元額と、2枚のカードを比べたときの損益分岐も分かります。
  • 複利計算ツール(積立・配当再投資のシミュレーション)
    毎月の積立額、初期投資額、想定利回り、期間から、複利で増えた場合の資産の目安を計算する無料ツールです。元本と運用益の内訳、年ごとの推移表、配当を再投資しない場合との差も確認できます。

このツールは入力した数字をもとに計算するだけのもので、入力内容はどこにも送信・保存されません。計算結果は前提に基づく目安で、将来の成果を保証するものではありません。投資判断はご自身の責任で行ってください。
