日経平均・S&P500の歴史から学ぶ暴落と暴騰｜なぜ株価は大きく動いたのか

※本記事内の数値は、値動きの規模感をつかんでいただくための概算値です。年央値や高値・安値の概算を用いている箇所があり、公式の終値そのものではありません。正確な数値は日本経済新聞社(日経平均株価)やS&P Dow Jones Indices(S&P500)などの公式データでご確認ください。また本記事は将来の値動きを予測・保証するものではなく、特定の投資判断を推奨するものでもありません。

「歴史は繰り返さないが、韻を踏む」という言葉がありますが、株式市場の歴史を振り返ると、暴落にはいくつかの共通したパターンがあることが分かります。逆に言えば、過去に何が起きたかを知っておくことは、今後どこかで市場が大きく動いたときに、冷静さを取り戻す助けになります。

この記事では、日経平均株価とS&P500(米国の代表的な株価指数)について、過去40年ほどの値動きを振り返りながら、代表的な暴落・暴騰がなぜ起きたのかを整理します。

日経平均株価の歴史:バブルとその崩壊、そして2024年の最高値更新

①バブル最高値(1989年)→バブル崩壊

日経平均株価は1989年12月29日、38,915円という史上最高値をつけました。1980年代後半、日本は低金利政策や旺盛な不動産投資を背景に、株価・地価が実体経済から大きく乖離するほど上昇する「バブル経済」を経験していました。

しかし1990年に入ると、日本銀行の金融引き締め(公定歩合の引き上げ)や大蔵省による不動産融資の総量規制をきっかけに、株価は急落を始めます。1992年には14,309円まで下落し、ピークからの下落率は6割超に達しました。ここから日本経済は「失われた10年」、さらには「失われた30年」とも呼ばれる長期低迷期に入っていきます。

なぜ起きたか:実体の裏付けを欠いた資産価格の急騰(バブル)は、金融引き締めなどのきっかけで急速に巻き戻されやすいとされています。バブル形成時の過剰な信用(借金による投資)が、崩壊時には逆回転して下落を加速させたと説明されることが多い出来事です。

→ 日本のバブル崩壊はなぜ起きたか、詳しくはこちら

②ITバブル崩壊と不良債権問題(2000年〜2003年)

2000年前後、インターネット関連企業への期待から世界的に株価が上昇する「ITバブル」が起こります。日経平均も2000年に20,000円台まで戻しましたが、その後ITバブルが崩壊。さらに日本国内ではバブル崩壊以降の不良債権処理が長引き、金融システム不安も重なったことで、2003年には7,972円まで下落しました。

なぜ起きたか:実際の収益に見合わない期待だけで買われていたIT関連株の失望売りに加え、日本特有の事情(銀行の不良債権問題)が重なり、下落が長期化・深刻化したとされています。

→ ITバブル崩壊はなぜ起きたか、詳しくはこちら

③リーマンショック(2008年〜2009年)

2008年9月、米国の大手投資銀行リーマン・ブラザーズが経営破綻したことをきっかけに、世界的な金融危機が発生しました。震源地は米国のサブプライムローン(信用力の低い人向けの住宅ローン)問題でしたが、金融機関同士が複雑に結びついていたことで危機は世界中に連鎖。日経平均は2009年3月に7,054円まで下落しました。

なぜ起きたか:住宅バブルの崩壊で不良債権化した金融商品が世界中の金融機関に広がっており、「どの金融機関がどれだけ損失を抱えているか分からない」という不信感が、金融機関同士の資金の貸し借りを止め、実体経済全体を巻き込む危機に発展したと説明されています。

→ リーマンショックはなぜ世界中に連鎖したか、詳しくはこちら

④コロナショック(2020年)

2020年、新型コロナウイルス感染症の世界的な拡大により、各国が都市封鎖(ロックダウン)などの措置を取ったことで経済活動が急停止。日経平均は2020年初めの23,386円あたりから、わずか1か月程度で16,552円まで急落しました。

なぜ起きたか:感染症拡大という実体経済への直接的なショックに加え、「経済の先行きがどうなるか全く読めない」という不確実性が、投資家のリスク回避姿勢を一気に強めたためとされています。一方で、各国政府・中央銀行による大規模な財政出動・金融緩和もあり、株価はその後急速に回復しました。

→ コロナショックはなぜ急落・急回復したか、詳しくはこちら

⑤2024年8月の急落

2024年、日経平均は2月に34年ぶりに1989年の最高値を更新し、7月には42,000円台まで上昇しました。しかしその直後の8月5日、日本銀行の追加利上げをきっかけとした急激な円高と、それに伴う「円キャリートレード」(低金利の円を借りて外貨建て資産に投資する取引)の巻き戻しが重なり、日経平均は1日で過去最大となる4,000円超の下落を記録しました。

なぜ起きたか:金利差を前提に組まれていた取引が、金利差の縮小観測によって一斉に解消され、売りが売りを呼ぶ展開になったと説明されています。その後、市場は比較的短期間で落ち着きを取り戻しました。

S&P500の歴史:米国株式市場の主な下落局面

①ブラックマンデー(1987年)

1987年10月19日、米国株式市場は1日で20%超下落するという歴史的な暴落に見舞われました。この日は「ブラックマンデー(暗黒の月曜日)」と呼ばれています。

なぜ起きたか:明確な単一の原因は特定されていませんが、当時普及し始めていたプログラム売買(コンピューターが自動的に売り注文を出す仕組み)が下落を加速させたことや、それまでの株価上昇が過熱していたことなどが要因として指摘されています。

→ ブラックマンデーの詳しい背景はこちら

②ITバブル崩壊(2000年〜2002年)

日経平均の項でも触れた通り、2000年前後の米国でもインターネット関連企業への過剰な期待が株価を押し上げていました。バブル崩壊後、S&P500は2000年3月の高値から2002年10月の安値まで、半分近く下落しました。

③リーマンショック(2008年〜2009年)

米国発の金融危機であるリーマンショックは、S&P500にも大きな打撃を与えました。2007年10月の高値から2009年3月の安値まで、S&P500は半分以下まで下落しました。

④コロナショック(2020年)

2020年2月の高値から、わずか1か月程度でS&P500は3割超下落しました。ただしその後の回復も早く、同年末には感染拡大前の水準を上回っています。

⑤インフレ・利上げ局面の下落(2022年)

2022年は、記録的なインフレ(物価上昇)を抑えるため、米国の中央銀行(FRB)が急速な利上げを行った年でした。金利の上昇は将来の企業利益の現在価値を目減りさせるため株価にはマイナスに働きやすく、S&P500は年間を通じて下落し、10月には年初来安値をつけました。

歴史から見えてくること

こうして振り返ると、暴落にはいくつかの型があることが見えてきます。

  • 過熱した期待の反動型:バブル崩壊、ITバブル崩壊など。実体を超えて買われていたものが、きっかけをもって急速に巻き戻される。
  • 金融システムの機能不全型:リーマンショックなど。信用不安が連鎖し、実体経済全体に波及する。
  • 外的ショック型:コロナショックなど。市場外の出来事が、先行き不透明感を通じて急落を引き起こす。
  • 金利・為替の急変型:2024年8月の急落、2022年の下落など。金利差を前提にした取引の巻き戻しや、将来利益の現在価値の目減りが株価を押し下げる。

もう一つ共通しているのは、どの暴落も、その後の期間で見れば回復しているという点です。もちろん過去の回復が将来の回復を保証するものではなく、日本のように回復に数十年を要したケースがあるのも事実です。ただ、暴落の渦中で慌てて売却してしまうと、その後の回復局面の利益を得られなくなる、という構造は多くの暴落に共通しています。

長期・積立・分散という、このサイトで繰り返し触れている投資の基本的な考え方は、こうした歴史を踏まえたうえでのものだと理解しておくと、実際に相場が大きく動いたときにも、判断の軸を持ちやすくなるはずです。
