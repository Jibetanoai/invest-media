ボリンジャーバンドとは?標準偏差から見る値動きの目安を初心者向けに整理

チャート画面を開いたとき、株価やレートを包み込むように描かれた「バンド(帯)」を見たことはないでしょうか。あれがボリンジャーバンドです。移動平均線と並んで表示されることが多く、証券会社のアプリでは初期設定のまま使える定番のテクニカル指標のひとつです。

ただ、「±2σを超えたら売り」といった断片的な説明だけを覚えてしまうと、実際の相場では戸惑う場面が出てきます。この記事では、ボリンジャーバンドの土台にある標準偏差という統計の考え方から順に整理し、初心者の方が「何を表している線なのか」を自分の言葉で説明できる状態を目指します。

ボリンジャーバンドとは何か — 移動平均線に「ばらつき」を足したもの

ボリンジャーバンドは、米国のテクニカルアナリストであるジョン・ボリンジャー氏が1980年代前半に発表した指標です(外為どっとコム)。

構造はシンプルで、次の2つの要素でできています。

  • 中心線:一定期間(20日など)の単純移動平均線
  • 上下のバンド:中心線から標準偏差(σ:シグマ)の1倍・2倍・3倍だけ上下に離した線

移動平均線が「最近の値動きの平均的な位置」を示すのに対し、ボリンジャーバンドはそこに「最近の値動きがどれくらい散らばっているか」という情報を重ねています。つまり、平均値+ばらつきの幅を1つのチャートで見るための道具、と捉えると理解しやすいでしょう。

線の名称中身
+2σ / +1σ移動平均 + 標準偏差×2 / ×1
ミッドバンド単純移動平均線(期間20が一般的)
−1σ / −2σ移動平均 − 標準偏差×1 / ×2

標準偏差(σ)ってそもそも何?

標準偏差は、データがどれだけ散らばっているかを表す統計の数値です。難しそうな名前ですが、発想自体は日常的なものです。

たとえばクラスのテストで、平均点が60点だったとします。全員が55〜65点に固まっているクラスと、20点〜100点までバラバラなクラスでは、同じ「平均60点」でも意味合いがまったく違います。この「バラつき具合」を1つの数字にしたものが標準偏差です。

相場に当てはめると、標準偏差が小さい=最近の値動きが落ち着いている、標準偏差が大きい=最近の値動きが荒い、ということになります。ボリンジャーバンドの幅が広がったり狭まったりして見えるのは、この標準偏差が日々変化しているからです。

±1σ・±2σ・±3σに収まる「確率」の話

統計学では、データが正規分布(左右対称の釣鐘型の分布)に従うと仮定した場合、次のような目安が知られています(Fintokei、マネーパートナーズ)。

  • ±1σの範囲に収まる確率:約68.3%
  • ±2σの範囲に収まる確率:約95.4%
  • ±3σの範囲に収まる確率:約99.7%

ここから「価格が±2σを超えるのは全体の5%程度のレアなこと」→「行き過ぎだから戻るのでは」という発想が出てきます。これがボリンジャーバンドが逆張り指標として紹介されがちな理由です。ただし、この解釈には後述する重要な前提があります。

チャート上での基本的な見方4パターン

バンドの形状には名前が付けられており、国内の証券会社などの解説では次の4つに整理されることが多くなっています(OANDA証券、外為どっとコム)。なお、スクイーズやバンドウォークといった用語は考案者のジョン・ボリンジャー氏の解説でも使われますが、4分類のまとめ方自体は解説サイトによって差があります。名前を覚えること自体が目的ではなく、「バンドの幅がどう変化しているか」を追うのがポイントです。

1. スクイーズ(収縮)

バンドの幅が狭くなっている状態です。読み取れるのは「直近の値動きの振れ幅が小さい状態が続いている」という事実までで、その後に必ず大きな動きが来るわけではありません。実際、バンドが広がりかけてもすぐに元の狭いレンジへ戻る「ヘッドフェイク(だまし)」と呼ばれる動きも知られています(Fintokei)。「次に大きく動く前触れ」と決めつけて読むと、外れる場面が出てきます。

2. エクスパンション(拡大)

狭まっていたバンドが上下に広がっていく状態です。値動きの振れ幅が大きくなり始めたことを示し、新しいトレンドの発生局面として説明されることが多い形です。

3. バンドウォーク

価格が+2σ(または−2σ)の線に沿うように、張り付いたまま進んでいく状態です。トレンドが継続した結果としてこの形が現れる、と説明されます。ただし「バンドウォークが続いている」と判断できるのは、ある程度その形が出そろった後であり、リアルタイムで「ここから始まる」と見分けられる性質のものではない点には注意が必要です。

4. ボージ(拡大の極)

エクスパンションを経て、バンド幅が最大限まで広がりきった状態を指します。値動きの振れ幅がピークに達した局面にあたり、この後はバンド幅が縮小に向かうことが多いとされます(OANDA証券)。

こうして並べると、4つの型はいずれも「バンド幅が狭い → 広がる → 広がりきる → また狭まる」というサイクルの、どの段階にいるかを言い換えたものだと分かります。

「±2σにタッチ=反転」とは限らない理由

初心者がつまずきやすいのがここです。±2σを超えるのは統計的にレア、という説明を素直に受け取ると、「+2σに触れたら売り」という単純なルールが成り立ちそうに思えます。しかし実際には、次の3つの理由から、そう単純にはいきません。

理由1:相場のリターンは正規分布にきれいには従わない

±2σで約95%という数字は、あくまで正規分布を仮定したときの話です。実際の金融市場の値動きには「ファットテール」と呼ばれる性質があり、理論上はごくまれなはずの大きな変動が、正規分布の想定よりも高い頻度で起こることが知られています(フジトミ証券)。確率の数字は目安であって、保証ではありません。

理由2:バンド自体が動く

ボリンジャーバンドは固定された壁ではありません。価格が動けば標準偏差も移動平均も変わり、バンドの位置と幅も変わります。「上限に達した」と思っても、上限そのものが上に伸びていくことは珍しくありません。

理由3:バンドウォークがある

トレンドが強い局面では、価格が±2σに張り付いたまま進むことがあります。この状態で「行き過ぎだから戻る」と考えて反対方向のポジションを取ると、進行中の値動きに逆らう形になります。考案者のジョン・ボリンジャー氏自身も、バンドへのタッチを単純な反転サインとして扱うことには慎重な立場を示しており、トレンドに沿った使い方を重視していると紹介されています(OANDA証券)。

つまりボリンジャーバンドは、「当たる予言装置」ではなく「今の値動きが普段と比べて荒いのか穏やかなのかを測る物差し」と捉えるほうが、実態に近いでしょう。

設定期間はどうする?

一般的によく使われるのは期間20(20日移動平均ベース)ですが、絶対的な正解があるわけではありません。期間の違いによる性質の差は、おおよそ次のとおりです。

  • 期間を短くする(例:10):価格の変化に敏感に反応し、シグナルの発生回数は増えるが、その分だけダマシも増えやすい
  • 期間を長くする(例:50):大きな流れをとらえやすい一方、反応は遅れやすい

注意しておきたいのは、パラメータを変えるたびに同じチャートでもバンドの形や「タッチした/しない」の見え方が変わる、という点です。自分が見ている時間軸(日足で数週間の動きを見たいのか、週足で数年を見たいのか)と設定が合っているかどうかは、あらかじめ確認しておきたいところです。

長期の積立投資をしている人にも意味はある?

「毎月コツコツ積み立てているだけなので、テクニカル指標は関係ない」と感じる方もいるかもしれません。実際、積立投資の売買タイミングをボリンジャーバンドで細かく調整しようとすると、積立本来の「買付タイミングを分散する」という性質と噛み合わなくなる面があります。

一方で、今の相場のボラティリティ(変動の大きさ)が普段より大きいのか小さいのかを知る材料としてなら、長期投資家にとっても知っておいて損のない知識です。バンドが大きく広がっている局面は、値動きの振れ幅が大きくなっている時期にあたります。保有を続けるのか、配分を見直すのか、あるいは一部を売却するのか — どの判断が適切かは、各自の資金計画や許容できる変動の幅によって変わりますが、その判断を「値動きの大きさ」という客観的な情報を踏まえて行える点に意味があります。

いずれにせよ、テクニカル指標はあくまで判断材料の一つであり、それだけで売買を決める性質のものではない、という前提は押さえておきたいところです。

実際にボリンジャーバンドを見るには — チャート環境の比較ポイント

ボリンジャーバンドは特別な有料ソフトがなくても、多くのネット証券の取引ツールやアプリに標準搭載されています。ただ、使い勝手には差があるため、口座を選ぶ・見直す際には次のような観点を比較してみるとよいでしょう(各社ツールの機能比較については株探、ザイ・オンラインなどのまとめが参考になります。いずれも2026年9月時点で確認。ランキングや機能内容は更新されるため、最新情報は各証券会社の公式サイトでご確認ください)。

  • テクニカル指標の搭載数と、同時表示できる本数:ボリンジャーバンドと出来高、移動平均などを重ねて見たい場合に効いてきます
  • パラメータ(期間・σの本数)を自由に変更できるか:σを3本まで表示できるか、期間を任意に設定できるかはツールによって異なります
  • スマホアプリでの操作性:外出先でチャートを確認する頻度が高い人ほど重要です
  • 過去チャートをどこまで遡れるか:長期の値動きを振り返って確認したい場合のポイントです
  • NISA口座(つみたて投資枠・成長投資枠)での取扱商品や手数料:分析ツールとは別軸の論点ですが、あわせて見ておきたい項目です

なお、NISA口座について「1人1金融機関しか作れない」と説明されることがありますが、正確には同一年内に利用できるのが1金融機関のみという意味です。所定の手続きをすれば年単位で金融機関を変更できます(ただし、その年にすでに買付を行っている場合、当年分の変更はできません)。一度決めたら一生変えられない、というわけではない点は押さえておくと、比較検討のハードルが下がるはずです。詳しい条件は金融庁や各証券会社の公式情報をご確認ください。

主要ネット証券はそれぞれ独自のチャートツールを提供しており、「どれが優れているか」は使う人の目的次第です。まずは複数社の公式サイトで、ツールのデモ画面や機能一覧を並べて見比べてみるのが分かりやすいでしょう。

まとめ:バンドは「壁」ではなく「物差し」

最後に要点を整理します。

  • ボリンジャーバンドは、移動平均線に標準偏差(ばらつき)の幅を重ねた指標
  • ±1σで約68%、±2σで約95%というのは正規分布を仮定した場合の目安であり、実際の相場では想定より高い頻度で外れることがある
  • バンド幅は「狭まる(スクイーズ)→広がる(エクスパンション)→広がりきる(ボージ)→また狭まる」というサイクルで変化し、その位置関係を見るのが基本
  • 「±2σタッチ=反転」と単純化するのは早計。考案者自身もトレンドに沿った見方を重視している
  • 長期投資家にとっては、売買タイミングというより「今の値動きの荒さを測る」材料として使える

実際に手を動かして確かめたい場合は、売買を伴わない形から試すこともできます。たとえば、自分が保有している(あるいは気になっている)銘柄・指数の過去チャートにボリンジャーバンドを表示し、「バンドが広がった後に実際は何が起きたか」を後追いで確認する方法です。そのうえで、使っているツールの表示項目や設定の自由度が物足りなければ、複数の証券会社のチャート機能を比較してみる、という順番で検討を進めるとよいでしょう。
