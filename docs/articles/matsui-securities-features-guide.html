松井証券とはどんな証券会社か

松井証券は1918年創業の老舗証券会社です。同社の沿革では、1998年に「国内初の本格的インターネット取引『ネットストック』を開始」したと記載されています。いわゆる「ネット証券」の中では、口座数の規模で大手に譲る面もありますが、長い運営実績とサポート体制を前面に出しているのが特徴です。

初心者がまず押さえておきたいポイントは、次の3つに整理できます。

  • 日本株の手数料は「1日の合計約定代金」で決まる方式(ボックスレート)で、1日50万円以下なら0円
  • 25歳以下は約定代金にかかわらず日本株の取引手数料が0円(米国株は対象外)
  • 投資信託は、保有しているだけで年率最大1%のポイントが付与される仕組みがある

逆に、取扱商品の幅(特に外国株)では他社に譲る部分もあります。以下で順番に見ていきます。

手数料:「1日いくら取引したか」で決まる方式

ボックスレート(1日定額制)の考え方

松井証券の日本株手数料は、1約定ごとではなく1日の約定代金合計で段階的に決まる「ボックスレート」という方式です。公表されている料金は、おおよそ次のようになっています(税込)。

1日の約定代金合計手数料
50万円以下0円
100万円以下1,100円
200万円以下2,200円
300万円以下3,300円
400万円以下4,400円
500万円以下5,500円

※100万円超の区分は、約定代金が100万円増えるごとに1,100円(税込)が加算される設計で、1億円超は110,000円(税込)が上限とされています。なお、ここでいう「1日の約定代金合計」は、取引所とPTSの現物取引と信用取引の合計金額です。

この方式のポイントは、1日のうちに何回取引しても、合計額が同じ枠内なら手数料が変わらないことです。たとえば10万円の銘柄を5回買っても合計50万円なので0円。少額で複数銘柄に分散したいスタイルとは相性が良い設計といえます。

25歳以下は約定代金にかかわらず無料

松井証券の分かりやすい特徴として、25歳以下は1日の約定代金がいくらであっても日本株の取引手数料が0円という設定があります(26歳になる月の最終営業日の取引分まで。現物・信用が対象で、米国株は対象外。また一日信用取引、NISA口座での取引、単元未満株の売却、立会外分売での買付、電話での取引は別の手数料体系のため対象外とされています)。年齢条件に当てはまる場合、約定代金が大きくなっても手数料額が変わらない設計になっている、という事実関係として押さえておくとよいでしょう。

なお、信用取引は預託した保証金を超える損失が生じる可能性がある取引です。手数料の条件だけで選ぶ対象ではなく、仕組みとリスクを理解したうえで利用を検討する前提のものです。

NISA口座の売買手数料は無料

NISA口座(つみたて投資枠・成長投資枠)での取引については、日本株・米国株・投資信託のいずれも売買手数料が無料とされています。ただし無料になるのは売買手数料であり、円貨決済時の為替手数料、投資信託の信託報酬、米国株配当にかかる現地課税などは別途発生します。「NISAならコストがゼロ」ではない点に注意が必要です。

注意すべき点:課税口座で50万円を超えると差が出る

一方で、ここは率直に書いておくべき部分です。ネット証券の中には、課税口座(特定口座・一般口座)でも日本株の売買手数料を金額上限なしで0円にしている会社があります(インターネット取引であること、各種交付書面を電子交付に設定することなどの条件が付きます)。つまり、

  • 26歳以上で
  • NISA枠ではなく課税口座を使い
  • 1日の約定代金が50万円を超える

という条件が重なると、松井証券のほうがコスト負担が重くなる場面があります。デイトレードや中〜大口の売買が中心の場合は、ご自身の取引額を手数料表に当てはめて確認しておくと判断しやすくなります。なお、デイトレード向けの「一日信用取引」については手数料0円の枠組みが別に用意されていますが、これはインターネットから新規建した当日中に決済した場合の扱いで、当日中に決済しなかった場合は1注文あたり3,575円(税込)がかかります。これも信用取引であり、損失が預託額を超える可能性がある点は同様です。

投資信託:「持っているだけ」で貯まるポイント

投信残高ポイントサービス(年率最大1%)

松井証券が力を入れているのが、2023年11月1日に始まった「最大1%貯まる投信残高ポイントサービス」です。仕組みはシンプルで、

  • 投資信託の月間平均保有金額に、
  • 銘柄ごとに設定された還元率(最大1%)を掛けて、
  • その12分の1が毎月ポイントとして付与される

という形です。NISA口座・特定口座を含むすべての口座が対象で、iDeCoで保有する投資信託も2024年8月1日から対象に加えられています。対象範囲も広く、取扱投資信託のほぼすべての銘柄が還元対象(ETF・REIT・米ドルMMFを除く)とされており、対象本数は1,991本(2026年10月1日時点、同サービスの対象銘柄数)と公表されています。

ただし「最大1%」の読み方には注意が必要

ここが、他媒体の紹介記事ではあまり強調されないポイントです。

「最大1%」はあくまで上限であり、実際の還元率は銘柄ごとに大きく異なります。たとえば残高ポイントの例として「eMAXIS Slim 全世界株式(オール・カントリー)」を挙げると、還元率は年0.0175%とされています。100万円を1年間保有した場合、ポイントは175円相当という計算です。

なぜこれだけ差が出るのか。一般に、こうした残高還元の原資は投資信託の信託報酬(運用コスト)のうち販売会社に配分される部分だと説明されます。低コストのインデックスファンドは販売会社の取り分そのものが小さく設計されているため、還元率も構造的に低くなりやすい、という整理です。逆に、信託報酬が高めのアクティブファンドは還元率も高くなりやすい、という関係になります。

つまり、

  • 低コストのインデックスファンド中心で積み立てる場合、還元率の差は小さく、他社と比べても大きな差になりにくい
  • 信託報酬が比較的高めのファンドを保有する場合、還元率の数字自体は相対的に大きくなりやすい

という整理になります。

ただし、ここは順序を取り違えないよう注意が必要です。還元率が高い銘柄はもともと信託報酬も高めである傾向があるため、ポイント還元を理由に保有商品を選ぶと、受け取るポイントを上回るコストを負担する結果になる場合があります。商品選びはコスト・中身・方針を軸に考え、ポイントはあくまで副次的な比較要素として見るのが一般的な考え方です。

「最大1%」という数字だけで判断せず、自分が検討している具体的な銘柄の還元率と信託報酬を並べて公式の銘柄リストで確認するのが確実です。そしてもう一点、このサービスは毎月のエントリーが必要とされているため、手続きを忘れると付与されない点にも注意してください。

クレカ積立(JCBカード)

2025年5月24日から、JCBオリジナルシリーズのカードを使った投資信託のクレカ積立にも対応しています(NISA口座を含む全口座で利用可)。還元率はカードのグレードと、クレカ積立以外の月間ショッピング利用額で変わる設計です。

  • プレミアムカード(JCBゴールド、プラチナなど):月5万円以上のカード利用で最大1.0%、5万円未満なら最大0.5%
  • 一般カード(JCBカードWなど):月5万円以上のショッピング利用で最大0.5%、5万円未満だとポイント付与なし

付与されるのはJCBのJ-POINTです。「カード利用額の条件を満たさないと率が下がる・付かない」という設計なので、普段からJCBカードをメインで使っているかどうかで価値が変わります。クレカ積立の還元と投信残高ポイントは別の仕組みなので、両方を受け取れる形になります。

クレカ積立で設定できる投資信託は1,864銘柄(クレカ積立対象の本数、2025年4月16日時点の公式公表値。これ以降の更新値は公表が確認できていないため、現在の本数は公式サイトでご確認ください)とされており、ラインナップの幅は比較的広いという見方ができます。ただし本数の多さと自分に合う商品があるかは別の話なので、検討している銘柄が対象かどうかは個別に確認するのが確実です。積立可能額の範囲や引落日などの細かい条件も、申込前に公式の案内で確認しておきたい部分です。

NISAへの対応状況

NISAについては、制度の両枠に対応しています。

  • つみたて投資枠の対象投資信託:292銘柄(2026年9月28日以降の公表本数。新規取扱いにより随時増減するため、最新本数は公式サイトまたは金融庁の対象商品届出一覧で確認してください)
  • 成長投資枠:日本株、米国株、投資信託に対応(整理・監理銘柄、高レバレッジ型・毎月分配型などは制度上の除外対象)
  • 売買手数料:NISA口座での売買手数料は無料(為替手数料・信託報酬等は別途)
  • クレカ積立:NISA口座でも利用可

加えて、簡単な8つの質問に答えると資産配分の提案を受けられるロボアドバイザー型のツール(投信工房)が無料で使え、提案されたポートフォリオをそのまま積立設定に反映できます。「何を何%買えばいいのか分からない」という段階では、入口のハードルを下げる仕掛けとして機能する場合があります。ただし、提案は一般的なモデルに基づくものなので、最終判断は自分で行う前提で使うものです。

サポート体制:第三者評価の状況

松井証券が長く評価されてきたのがサポートです。HDI-Japan(ヘルプデスク協会)が実施する「HDI格付けベンチマーク 2025年【証券業界】」において、「問合せ窓口」「Webサポート」の2部門で最高評価の三つ星を15年連続で獲得したと発表されています。

有人チャットは窓口によって受付時間が異なります。FX・米国株に関する窓口は月〜金曜 7:00〜24:00(日本の祝日も対応、1月1日を除く)まで拡大されており、日本株・NISA・投資信託などその他の問い合わせは平日8:30〜17:00です。電話窓口も平日8:30〜17:00が基本で、AIチャットは24時間利用できます。

ネット証券は「安いが自己責任で、聞く相手がいない」と感じやすい世界なので、最初の数年で分からないことを人に聞きたいという場合には、手数料以外の判断材料になり得る部分です。逆に、すべて自分で調べて完結できる場合には差になりにくい要素といえます。

米国株・その他のサービス

  • 米国株の売買手数料:課税口座では約定代金の0.45%(税込0.495%、上限は税込22米ドル)がかかります。NISA口座での売買手数料は無料です
  • 為替手数料:取引通貨を「米ドル」にする外貨決済の場合、米ドル⇔円の為替手数料は0銭です(2023年12月4日から、買付時・売却時ともに恒久的なサービスとして無料化)。一方、取引通貨「円」(円貨決済)を指定する取引はこの無料化の対象外で、1米ドルあたり25銭の為替手数料がかかります。決済通貨の設定によってコストのかかり方が変わるため、ここは事前に確認しておきたい部分です
  • 取引時間の拡大:2026年12月から、米国株の取引時間を現行の12時間から23時間へ拡大する予定と発表されています(現地2026年12月6日の取引分から。日本時間10:00〜翌9:00、冬時間は11:00〜翌10:00)
  • 外国株の範囲:ただし外国株は米国株のみ。米国株を除く外国株(中国株、インド株など)は取り扱っていないため、広く外国株に投資したい場合には選択肢が限られます(国債・債券、金・プラチナなども取扱対象外とされています)
  • そのほか、FX、先物・オプション、信用取引なども提供しています(信用取引・FX・先物オプションは、いずれも預託額を超える損失が生じる可能性のある取引です)

相性を確かめるためのチェックポイント

ここからはあくまで一般的な整理です。自分の条件に当てはめる材料として読んでください。

条件が噛み合いやすいケース(一般的な整理として)

  • 25歳以下で、日本株の売買を検討している(約定代金にかかわらず手数料が0円)
  • 1日の取引額が50万円以内に収まる少額・分散スタイル
  • NISAをメインに使う(売買手数料が無料になるため)
  • 分からないことを電話やチャットで聞ける環境を重視したい

条件が噛み合いにくいケース(一般的な整理として)

  • 26歳以上で、課税口座で1日50万円超の日本株売買を頻繁に行う
  • 米国以外の外国株や、債券などに投資したい
  • 低コストインデックスファンドだけで積み立てる予定(残高ポイントの差が小さく、他社との優劣が付きにくい)
  • 普段使っているカードや経済圏がJCB系ではない(クレカ積立の条件を満たしにくい)

どちらに近いかは、年齢・取引額・検討している商品で変わります。「良い/悪い」ではなく「自分の使い方と噛み合うか」という見方が現実的です。なお、ポイント還元の有利さを理由に保有商品を決めるのは、前述のとおりコスト面で逆効果になる場合があります。

証券会社を比べるときに見るべき5つの観点

松井証券に限らず、口座を選ぶときは次の順番で確認すると比較がブレにくくなります。

  • 自分の取引スタイルでの実際の手数料

「無料」の条件(金額上限・年齢・口座種別・対象商品・電子交付などの設定)を、自分の取引額に当てはめて計算する。宣伝文の「無料」は条件付きであることが普通です。

  • 検討している商品が実際に買えるか

つみたて投資枠の本数、米国以外の外国株、債券、REITなど。将来広げたい範囲も含めて確認します。

  • ポイント還元は「上限」ではなく「自分の銘柄の率」で見る

クレカ積立の還元率と、保有残高の還元率は別物です。両方について具体的な銘柄・カードでの数字を確認し、あわせて信託報酬そのものの差も並べて比べます。

  • アプリ・ツールの使いやすさ

毎月触るものなので、画面の分かりやすさは軽視できません。多くの会社がデモ画面や解説動画を公開しています。

  • サポートの手段と時間帯

電話・チャット・メールのどれが使えるか、何時まで対応しているか、窓口によって時間が違わないか。慣れないうちは効いてくる項目という見方もあります。

なお、NISA口座は年単位で金融機関を変更できるものの、手続きには手間がかかります。最初に複数社の公式サイトで手数料表とラインナップを並べて確認しておくと、後からの乗り換え負担を減らしやすくなります。NISA口座が1人1口座である一方、課税口座(特定口座)は金融機関ごとに開設できるため、「積立はA社、個別株はB社」という使い分けを選ぶ人もいます。

学びの面では、証券会社が無料で公開しているマーケットレポートやセミナー、NISA制度の解説書籍、金融庁や投資信託協会といった公的機関の資料も、特定の商品に偏らない情報源として参考になります。

まとめ:比較の進め方

松井証券の特徴を一文でまとめると、「少額・分散、または25歳以下での日本株取引と、投資信託の保有残高ポイント、そしてサポートの第三者評価に寄った設計のネット証券」といえます。一方で、課税口座での大口売買や米国以外の外国株については、他社のほうが条件が良い場面があります。

口座を比較する際の確認方法としては、次のような手順が挙げられます。

  • 自分の取引額を書き出して、候補2〜3社の手数料表に当てはめて計算してみる(候補を絞り込む手がかりになります)
  • 検討している投資信託の名前を決めて、各社のポイント還元率と信託報酬を公式の銘柄リストで比べる

数字を自分の条件に置き換えてから比較すると、「どこが一番お得か」という問いから「自分の使い方に合うのはどこか」という問いに切り替えやすくなります。口座開設の比較を進める際も、ランキングの順位より、この2つの確認を先に済ませておくほうが判断材料がそろいます。

松井証券の最新の手数料・サービス内容は、公式サイトで確認できます(PR):松井証券のNISA〜100円から始められる〜

用語ミニ解説

  • 約定代金(やくじょうだいきん):売買が成立した金額のこと。「100円の株を100株」なら約定代金は1万円です。
  • ボックスレート:1日の約定代金の合計額に応じて、段階的に手数料が決まる方式。松井証券の日本株手数料で使われています。
  • 信託報酬:投資信託を保有している間、継続的にかかる運用コスト。運用会社・販売会社・信託銀行で分配されます。
  • 投信残高ポイント:投資信託の保有残高に応じて付与されるポイント。還元率は銘柄ごとに設定されます。
  • つみたて投資枠 / 成長投資枠:NISAの2つの枠。前者は長期・積立向けに選定された投資信託が対象、後者は個別株などより幅広い商品が対象です。
  • 為替手数料:円と外貨を交換するときのコスト。米国株投資では、売買手数料とは別に確認しておきたい項目です。
  • 信用取引:証券会社から資金や株式を借りて行う取引。利益も損失も自己資金より大きくなり得るため、預託した保証金を超える損失が生じる可能性があります。
