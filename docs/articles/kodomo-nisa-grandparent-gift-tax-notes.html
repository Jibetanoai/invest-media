祖父母からの援助でこどもNISAを始めるときの注意点|贈与税の基本と記録の残し方

※本記事には、金融機関のサービス紹介としてアフィリエイトリンクを含む場合があります。

「孫のために」と祖父母がまとまったお金を出してくれる。そのお金を、2027年1月に始まる予定のこどもNISA(報道などで「こども支援NISA」と呼ばれることもあった制度。本記事では以下「こどもNISA」で表記を統一します)で積み立てていきたい——そんな相談が増えているようです。

ただ、ここで一度立ち止まっておきたいポイントがあります。親が自分のお金で子ども名義の口座に積み立てる場合と、祖父母からの援助を使う場合とでは、税務上の整理の仕方が変わってくるからです。具体的には「贈与税がかかるのか」「誰のお金として扱われるのか(名義預金の問題)」「相続のときにどう扱われるのか」という3つの論点です。

もっとも、論点そのものは数が限られています。先に全体像を把握しておけば、何を調べ、何を記録すればよいかの見通しは立てやすくなります。この記事では、制度の概要をおさらいしたうえで、贈与税の基本と、実務でよく挙げられる記録の残し方を整理します。なお、贈与税や相続税の結論は、他の贈与の有無・相続財産の規模・遺言の内容といった個別事情で変わります。金額が大きいケースや家族構成が複雑なケースは、税理士や所轄の税務署に確認する前提で読み進めてください。

まず前提:こどもNISAの基本スペック

こどもNISAは、18歳未満(その年1月1日において18歳未満)を対象とする非課税投資制度です。2025年12月26日に閣議決定された令和8年度(2026年度)税制改正の大綱で骨格が示され、その後「所得税法等の一部を改正する法律」(令和8年3月31日成立・公布)で制度化されています。一方で、払出しの確認書類や口座管理の細かい運用ルールは、政令・省令や各社の実務でこれから詰まる部分が残っています。施行時期や確定済みの内容は、金融庁・財務省および各金融機関の公表資料で最新版を確認するのが確実です。

法令・大綱および各社の案内ベースで、現時点の主な内容は次の通りです。

  • 対象年齢:0〜17歳(財務省「令和8年度税制改正の大綱の概要」)
  • 年間投資枠:60万円(同)
  • 生涯の非課税保有限度額:600万円(同)
  • 対象商品:つみたて投資枠と同様の、長期の積立・分散投資に適した一定の投資信託(法律案要綱では「公募等株式投資信託の受益権」)
  • 非課税保有期間:各社の案内では無期限と説明されています(大綱・法律案要綱の公表部分には保有期間の明示がないため、確定情報は各社・金融庁の案内で確認してください)
  • 払出し(引き出し):段階が分かれています。

- 災害等の特定事由による場合を除き、その年3月31日時点で12歳である年(おおむね中学校に入学する年)の前年以前は払出しができない(令和8年度税制改正の大綱)

- その年以後は、教育費または生活費の支払いに充てるためであることなどを記載した書類を提出することで払出しが可能(法律案要綱)。あわせて「子ども本人の同意」を得たことを示す書類が必要とされています(どの支出が教育費・生活費にあたるかの細かい線引きは、まだ詳しく示されていない部分があります)

- それ以外の自由な払出しは18歳まで制限される

  • 18歳到達後:成人のNISAの非課税保有限度額(1,800万円)へ引き継がれる見込み(報道・各社案内ベース)
  • スケジュール:2026年10月1日から主要証券会社(楽天証券、SBI証券、マネックス証券、三菱UFJ eスマート証券、PayPay証券、松井証券など)で口座開設の事前申込受付が始まり、制度開始は2027年1月予定

以下の内容も、ルール確定後に変わる可能性がある点は念頭に置いてください。

なぜ「祖父母からの援助」だと贈与税の話になるのか

こどもNISAの口座は子ども本人の名義です。つまり、祖父母が出したお金で子ども名義の資産を買うと、形式上は「祖父母→孫への財産の移転」になります。これが贈与税の出発点です。

ここで多くの人がつまずくのが、「教育費なら贈与税は非課税」という話との関係です。

国税庁のタックスアンサーNo.4405(贈与税がかからない場合)では、扶養義務者(親・祖父母など)から生活費や教育費に充てるために取得した財産のうち「通常必要と認められるもの」は贈与税の対象外とされています。年間の学費や仕送りが110万円を超えても、それ自体で贈与税の心配をする必要はありません。

ただしこの非課税は、「生活費や教育費として必要な都度直接これらに充てるためのものに限られます」とされています。さらに同No.4405には、「生活費や教育費の名目で贈与を受けた場合であっても、それを預金したり株式や不動産などの買入資金に充てている場合には贈与税がかかることになります」と明記されています。つまり、こどもNISAで運用する原資は「都度払いの教育費」ではなく、通常の贈与(暦年課税)として考えるのが出発点になります。

参考までに、祖父母からのまとまった教育資金の援助に使われてきた「直系尊属から教育資金の一括贈与を受けた場合の贈与税の非課税」(受贈者1人あたり1,500万円まで)は、令和8年度税制改正の大綱で「適用期限(令和8年3月31日)を延長しない」とされました。国税庁の案内によれば、令和8年(2026年)4月1日以後はこの特例の適用を受けることはできません(ただし、令和8年3月31日までに特例の適用を受けた信託受益権または金銭等については、引き続き適用されます)。新たにこの選択肢を使うことはできないため、暦年の贈与をどう整理するかが実務上の中心になりました。

贈与税の基本:年110万円は「もらう側」で合計する

暦年課税の贈与税には、年間110万円の基礎控除があります。1月1日〜12月31日の1年間に贈与を受けた財産の価額の合計額が110万円以下であれば、贈与税はかからないというのが基本的な考え方です。

ここで押さえておきたいのが、110万円は「あげる人ごと」ではなく「もらう人ごと」に数えるという点です。

  • 祖父が60万円 + 祖母が60万円 → 子どもが受け取った合計は120万円 → 110万円を超える
  • 祖父母から60万円 + 親から50万円 → 合計110万円 → 基礎控除の範囲内

こどもNISAの年間枠は60万円なので、それ単体なら基礎控除の範囲に収まりやすい金額設計です。問題になりやすいのは、こどもNISAとは別に、お祝い金や学資保険の原資、まとまった現金援助などが同じ年に重なるケースです。「その年に子どもがいくら受け取ったか」を家族で把握しておくことが、地味ですが実務上は大きな意味を持ちます。

なお、110万円を超えた場合は、贈与により財産を取得した年の翌年2月1日〜3月15日に、受贈者(子ども)の名前で贈与税の申告と納税が必要になります。未成年の場合は、親権者が法定代理人として手続きを行うのが一般的です。

もう一つの制度:相続時精算課税

祖父母から孫への贈与では「相続時精算課税」という制度も選べますが、要件は贈与者が贈与をした年の1月1日において60歳以上の父母または祖父母など、受贈者が贈与を受けた年の1月1日において18歳以上の直系卑属である推定相続人または孫です。こどもNISAの対象者は18歳未満なので、孫自身がこの制度を使う場面は基本的にありません。令和6年(2024年)1月1日以後の贈与からは相続時精算課税にも年110万円の基礎控除が設けられ、相続財産に加算されるのは「基礎控除額を控除した残額」とされています(基礎控除は特定贈与者ごとに適用され、複数の特定贈与者から贈与を受けた場合は按分されます)。親世代が自分の親(祖父母)から贈与を受ける場面では関係してくる制度ですが、世代をまたぐ資金移動は暦年課税との選択や撤回不可の論点が絡み、個別性が高くなります。この領域は税理士に相談する前提で考えるのが現実的でしょう。

実務で問題になりやすい「名義預金」

税務上、より実務的に論点になりやすいのが名義預金(名義財産)です。

名義預金とは、口座の名義人と、実際にお金を出して管理している人が違う状態のこと。名義は孫でも、

  • もらった本人(または親権者)に「もらった」という認識がない
  • 資金を出した祖父母が通帳・印鑑・ログイン情報を管理し続けている
  • 実質的に祖父母が自由に出し入れできる

といった状態だと、贈与が成立していない=実質は祖父母の財産と判断され、相続のときに相続税の課税対象に含まれる可能性があると指摘されています。「毎年110万円以内で渡していたつもり」が、まとめて祖父母の財産として扱われてしまう、というのが税理士法人などの解説でよく挙げられる失敗パターンです。

贈与が成立するには、法律上「あげます」「もらいます」という双方の意思表示が必要です。子どもが幼い場合は親権者が法定代理人として受諾する形になります。言い換えれば、祖父母ではなく親(または子ども本人)の側が管理している状態になっているかどうかが見られる、ということです。

この点、こどもNISAは口座名義が子ども本人で、親権者が法定代理人として手続きを行い、払出しにも使途を記載した書類の提出などが求められる設計です。構造的には「子ども本人のための資産」という形が残りやすい制度と言えます。ただし、資金の出どころが祖父母であることの記録が残っていなければ、贈与があったことを示すのは難しくなります。ここが次の章の話です。

記録の残し方:実務でよく挙げられる5つのポイント

税務の世界では「あったことを示せるか」が重要になります。以下は、税理士法人や金融機関の解説で一般に挙げられている方法です。手間がかかるのは最初だけなので、家庭のルールとして仕組みにしてしまうと続けやすくなります。

1. 贈与契約書を、贈与のたびに作る

贈与者(祖父母)と受贈者(子ども、親権者が代理署名)の署名、日付、金額、振込先は、最低限そろえたい項目として挙げられます。ただし、書面があればそれだけで贈与が認められるというものではありません。実務では資金の管理実態も合わせて見られるため、書面と実態の両方をそろえる意識が必要です。

2. 現金手渡しより銀行振込にしておく

祖父母の口座から、子ども名義の銀行口座へ振り込む形にすると、「いつ・誰から・誰へ・いくら」が通帳に残ります。祖父母→親の口座→子どもの口座という経路は、誰からの贈与なのかが曖昧になりやすいと指摘されています。

3. 子ども名義の銀行口座を経由させる

こどもNISAへの入金を子ども名義の銀行口座から行う流れにすると、資金の流れが一本の線になります。証券口座の入金方法(どの銀行からの入金に対応しているか、自動入金サービスがあるか)は、口座開設前に確認しておきたいポイントです。

4. 「その年に子どもが受け取った贈与」の一覧を作る

祖父・祖母・親・その他の親族からの贈与を、年ごとに合計できる簡単な表で管理します。スプレッドシート1枚で足ります。110万円のラインを把握しておくことは、申告が必要かどうかを早めに判断する材料になります。

5. 毎年の金額や時期の決め方には注意する

「10年間、毎年60万円」とあらかじめ約束していた形だと、定期贈与(=総額600万円を分割で受け取る一つの贈与)と見られる余地が生じる、という指摘があります。これに対し、毎年その都度贈与契約を結び、贈与の実態が年ごとに独立していれば、金額が一定でも定期贈与とは別に扱われるという見解も実務上あります(いずれも税理士法人などの解説で紹介されている整理です)。積立投資の性質上、定額の積立が自然なケースもあり、画一的な正解があるテーマではありません。金額規模が大きい場合は、個別に専門家の確認を取る領域だと考えてください。

相続まで視野に入れる:7年ルールと「孫への贈与」

暦年課税の生前贈与加算は、対象期間が「相続開始前3年以内」から「相続開始前7年以内」へ延長されました。経過措置があるため、加算期間がフルに7年となるのは令和13年(2031年)1月1日以後の相続からです(なお、令和8年12月31日までの相続は3年以内、令和9年1月1日〜令和12年12月31日の相続は令和6年1月1日から死亡日までの期間が対象)。また、相続開始前3年超7年以内に受けた贈与については、その財産の価額の合計額から総額100万円を控除した残額が加算されます。贈与者が亡くなると、その一定期間の贈与が相続財産に足し戻される仕組みです。

ここで押さえておきたいのが、この加算は原則として相続、遺贈や相続時精算課税に係る贈与によって財産を取得した人に対して適用されるという点です。孫は通常は法定相続人ではないため、この加算の対象外になるケースがあります。ただし、

  • 孫が代襲相続人になっている
  • 遺言で孫に財産を遺贈している
  • 孫が生命保険金の受取人になっている

といった場合は対象になり得ます。「孫への贈与なら加算されない」と単純化できる話ではないので、家族構成と遺言の内容を合わせて確認してください。

口座を開く前に整理しておきたいこと

税務の整理と並行して、実務面でも先に考えておきたい論点があります。

① 原資をどう位置づけるか

一般的な解説では、祖父母からの援助を「都度の教育費」として学費の支払いに充て、こどもNISAは親の資金で積み立てるという整理の仕方も紹介されています。この場合、援助部分については前述の「通常必要と認められる教育費」の考え方で整理できるため、論点は少なくなります。一方で、祖父母の資金をこどもNISAの原資にする形も当然あり得ます。どちらが適切かは家計や相続の状況によって変わるので、方針を決める段階で専門家に確認するのが安全です。

② 親のNISAとの役割分担

子ども名義で積み立てると、18歳以降は子ども本人の資産になります。払出し制限がある一方、親が自由に使える資金ではなくなるという性質があります。教育費のうち「確実に必要な分」と「余裕資金」を切り分け、前者は流動性の高い手段で持つという考え方も紹介されています。どちらが優れているという話ではなく、家計の状況によって適した形は変わります。

③ 金融機関を選ぶ観点

こどもNISA口座は、すべての金融機関を通じて1人1口座のみで、開設後に金融機関を変更することはできないとされています(野村證券・楽天証券の案内)。ただし、まったく動かせないわけではなく、各社の案内では「口座を廃止して他社で新規開設することは可能だが、廃止する場合はそれまでに受け取った利益や含み益に課税される」という整理が示されています。いずれにしても、やり直しのコストは小さくないため、最初の比較に時間をかける価値があります。

前提として、こどもNISA口座の開設にあたっては、親権者自身がその金融機関に証券口座を持っていることが必要とされる例があります(楽天証券は親権者の同社口座が必要、野村證券も親権者自身の口座開設が別途必要と案内しています)。候補となる会社ごとに条件を確認しておきたいところです。

比較の観点としては、次のような項目が挙げられます(いずれも2026年10月時点の各社公表条件を前提としたものです。最新の内容は各社の公式ページでご確認ください)。

  • つみたて投資枠対象商品のうち、どの範囲を取り扱っているか
  • 最低積立金額や積立日の設定の柔軟さ(例:楽天証券は月100円からと案内)
  • 入金方法(子ども名義の銀行口座からの入金・自動入金に対応しているか)
  • 未成年口座での各種サービスの扱い(クレジットカード積立の可否やポイント付与の条件は会社ごとに異なります。たとえば楽天証券は対象ファンドの残高に応じたポイント付与を案内しています)
  • 取引報告書や年間取引報告書など、記録の取り出しやすさ
  • 親の口座と同じ会社にまとめるか、分けるか(管理のしやすさ・画面の見やすさ)

各社は2026年10月から事前申込の受付を開始していますが、取扱商品や付帯サービスの条件は今後更新される可能性があります。制度開始前のこの時期は条件がまだ出そろう途中なので、複数社の公式ページで最新の条件を横並びで確認してから決める、という進め方にも合理性があります。

まとめ

  • こどもNISAの原資に祖父母の援助を使う場合、「都度払いの教育費は非課税」という扱いは使いにくく、通常の贈与(年110万円の基礎控除)で考えるのが出発点
  • 110万円はもらう側(子ども)の年間合計で数える。他の援助との合算に注意
  • 実務で論点になりやすいのは名義預金。形式(名義)と実質(管理)がそろっているかが見られる
  • 記録方法としては、贈与契約書・銀行振込の記録・年間の受贈一覧がよく挙げられる
  • 相続まで含めた整理や金額が大きいケースは、税理士に相談する領域

次の一歩としては、(1)その年に子どもが受け取る予定の贈与を家族で洗い出す、(2)贈与契約書のひな形を用意する、(3)候補となる金融機関の未成年口座の条件を2〜3社比べてみる——この順で進めると整理しやすいはずです。贈与税や相続の基本的な考え方は、国税庁のタックスアンサーでも確認できます。制度開始まで時間があるうちに、数字と書式を整えるところから始めてみてください。
