DMM株とは？日本株・米国株の手数料と取扱商品、NISA対応、向いている人を初心者向けに整理【2026年10月時点】

DMM株とはどんなサービスか

DMM株は、DMM.com証券が提供する株式取引サービスです。大きな特徴は、取扱商品を「国内株式」と「米国株式」に絞り込んでいる点にあります。総合証券やフルラインナップ型のネット証券が、投資信託・債券・iDeCo・FXなどを幅広く揃えるのに対し、DMM株は株式に特化してコストと取引ツールに資源を集中させた設計と言えます。

この「絞り込み」が、そのままメリットにもデメリットにもなります。株式売買のコストを抑えたい人にとっては魅力的ですが、投資信託の積立を軸に資産形成したい人にとっては、そもそも土俵が違う、ということになります。

まず押さえたい専門用語

  • 現物取引：自分の資金の範囲内で株を買う、もっとも基本的な取引方法。
  • 信用取引：証券会社に保証金を預け、資金以上の金額の取引や「売り」から入る取引ができる仕組み。利益も損失も大きくなりやすく、預けた保証金を超える損失が生じる可能性もあります。初心者がいきなり使う性質のものではありません。
  • 単元未満株（ミニ株）：通常100株単位の日本株を、1株から売買できるサービス。
  • 円貨決済／外貨決済：米国株を買うとき、円のまま発注する方式と、あらかじめ両替したドルで発注する方式のこと。
  • 為替スプレッド：円とドルを交換する際に上乗せされる実質的なコスト。手数料欄に表示されないため見落としやすい部分です。
  • つみたて投資枠／成長投資枠：NISAの2つの枠。つみたて投資枠は金融庁の基準を満たす投資信託・指定ETFのみが対象で、個別株は買えません。個別株やその他のETF・REITは成長投資枠で扱います。

手数料はどうなっている？（2026年10月時点）

国内株式

国内株式の現物取引手数料は、1約定ごとに55円〜880円（税込）という体系で、約定代金5万円以下なら55円（税込）からとされています。また、国内の信用取引手数料は約定金額にかかわらず0円と案内されています。

ただし、ここは冷静に見ておきたいところです。2026年時点では国内信用取引の手数料無料化は主要ネット証券の間でほぼ横並びになっており、それ自体が強い差別化要因とは言いにくくなっています。さらに国内現物取引については、所定の条件（たとえば楽天証券のゼロコースはSORの利用同意、SBI証券のゼロ革命は各種報告書の電子交付設定など）を満たすと手数料が無料になるコースを用意している主要ネット証券もあるため、「DMM株は国内現物も最安」という前提は成り立ちません。コスト面で比べるなら、自分の売買金額・頻度を当てはめて各社の体系を並べる必要があります。

また、かつて実施されていた「25歳以下は国内現物取引手数料が実質0円」という特典については、2026年3月末で終了したと案内されています。この種のキャンペーンは入れ替わりが早いため、年齢条件などを当てにする場合は、申込前に公式ページで現在も有効かを確認しておくのが安全です。

米国株式

米国株は、かつて「取引手数料0円」を打ち出していた時期があり、その情報が今もネット上に残っています。ただし現在は、約定代金×0.495%（税込）がかかる体系に変更されています（公式の手数料ページおよびFAQで案内）。約定代金が2.22ドル以下なら0ドル、4,444.45ドル以上では上限22ドル（税込）で頭打ちになる仕組みです。

さらに、円貨決済を選んだ場合は1ドルあたり25銭（片道）の為替コストが別途かかります（公式では外貨決済を選べばこの為替コストは発生しないと案内されています）。「手数料0円」という古い情報だけを見て比較すると実態とズレるので、米国株のコストは〈売買手数料＋為替コスト〉のセットで見るのが基本です。

NISA口座の場合

NISA口座内の取引については、国内株式・米国株式とも取引手数料が無料と案内されています。ただし対象銘柄や決済方法によって条件が設けられている場合があるため、米国株をNISAで扱う前提なら、公式の手数料ページとNISAページの両方で適用条件を確認しておくと安心です。

そのうえで、NISAでも別途かかるコストが2つあります。

  • 為替コスト：米国株を円貨決済で買う場合の1ドルあたり25銭は、NISAでも発生します。
  • 米国での配当源泉徴収（10%）：米国株の配当には、日米租税条約に基づく税率10%が現地で源泉徴収されます。しかもNISA口座では外国税額控除が使えません。課税口座なら確定申告で一部を取り戻せる余地がありますが、NISAでは国内が非課税で二重課税にならないためその調整ができず、米国配当株をNISAで持つ場合は現地課税分が引かれたままになります。

「NISAなら一切コストゼロ」ではない、という点はどの証券会社を選ぶ場合でも共通の注意点です。

なお、国内株式・米国株式の取引手数料（税抜金額で判定）の1%がDMM株ポイントとして還元される仕組みもあります。ただしこれは手数料に対する還元なので、手数料が0円になるNISA口座の取引では、還元も実質的に発生しません。「NISAでもポイントが貯まる」と読み違えないよう注意してください。

取扱商品とNISA対応：2026年に変わった点

DMM株のNISAでは、国内上場株式（ETF・REIT・ETNを含む）と、DMM株が選定した米国上場株式・ETFが対象とされています。米国株の取扱銘柄数は、ADRやETFを含めて約1,870銘柄とされています（比較サイトの集計値・2026年8月更新時点。正確な対象は公式の取扱銘柄一覧でご確認ください）。

そして2026年にかけて、ここが動きました。DMM株は2026年1月に株式累積投資サービス「つみたてかぶ」を開始し、さらに2026年6月8日からは、つみたてかぶで米国株式の積立にも対応しています。つみたてかぶは月1,000円以上・1円単位から設定でき、買付サイクルを「毎営業日」「毎週（曜日指定）」「毎月」のほか「2ヶ月毎」「3ヶ月毎」「4ヶ月毎」から選べる点が特徴です。

「つみたてかぶ」とNISAの枠の関係（ここを誤解しやすい）

つみたてかぶはNISA口座（つみたて投資枠・成長投資枠）でも利用できると案内されていますが、「つみたて投資枠で個別株を積み立てられる」という意味ではありません。NISAの制度上、つみたて投資枠で買えるのは金融庁の基準を満たす投資信託と指定されたETFだけで、個別株はつみたて投資枠の対象外です。なお公式では、NISAつみたて投資枠を使う場合はひと月あたり10万円を超える積立金額を指定できないとも案内されています。

整理すると次のようになります。

積立の対象使える枠
国内・米国の個別株成長投資枠（または課税口座）
つみたて投資枠の対象となる指定ETF等つみたて投資枠（具体的な対象銘柄は公式で確認）
投資信託（全世界株インデックスファンド等）DMM株では取扱なし

つまり「DMM株でつみたてかぶが始まったから、全世界株インデックスファンドの積立にNISAのつみたて投資枠が使える」という話ではない、という点に注意が必要です。投資信託そのものを取り扱っていないという構造は変わっていません。ここがDMM株を理解するうえで中心となるポイントです。

一方で、「DMM株は株式の積立ができない」という説明は2025年以前の情報に基づく古い内容である可能性があるため、こちらも併せて押さえておきたいところです。

単元未満株と「つみたてかぶ」の違い：好きなタイミングで1株だけ売買するスポット型の単元未満株サービスは提供されていない一方（保有している単元未満株については、発行会社への買取請求で換金する扱いとなり、1銘柄550円（税込）の手数料がかかると案内されています）、つみたてかぶでは積立という形で1円単位の金額指定による買付ができ、端数株の保有もできると案内されています。

投資信託が買えないということは、「全世界株式インデックスファンドを毎月コツコツ」という、いま最も一般的に語られる積立スタイルがDMM株だけでは完結しないことを意味します。また日本株のスポット購入は原則100株単位となるため、値がさ株を買おうとすると数十万円単位の資金が必要になる場面もあります。

向いている人・慎重に検討したい人

向いている可能性がある人

  • 日本株の個別銘柄を、ある程度の頻度で売買したい人
  • すでに信用取引の経験があり、各社のコストを比較したい人
  • 米国の個別株・ETFを自分で選んで買いたい人
  • すでにメイン口座を持っていて、株式取引用のサブ口座を探している人

信用取引は、資金以上の取引ができる分だけ損失も拡大しやすく、相場の動き方によっては預けた保証金を超える損失が生じる可能性があります。手数料の水準だけで取引手法を選ぶ対象ではなく、仕組みとリスクを理解していない段階では利用を見送る判断も含めて検討する領域です。

慎重に検討したほうがよい人

  • 投資信託の積立を資産形成の中心に据えたい人
  • iDeCoも同じ証券会社でまとめたい人
  • 数千円〜1万円程度で、好きなタイミングに日本株を1株ずつ買い集めたい人
  • NISAの生涯投資枠1,800万円（うち成長投資枠は1,200万円）を、投資信託も含めて幅広く使いたい人

「良い・悪い」ではなく、自分の投資スタイルと噛み合うかどうかという見方が現実的です。株式中心で動く人と、投資信託の自動積立で手間をかけたくない人とでは、同じサービスの評価が正反対になります。

証券会社を比較するときに見るべき5つの観点

DMM株に限らず、口座を開く前にチェックしておきたい観点を整理しておきます。

  • 取扱商品：投資信託・外国株・iDeCo・債券など、自分が使いたいものが揃っているか。将来やりたくなりそうなものまで視野に入れておくと、後から口座を増やす手間が減りやすくなります。
  • 手数料の構造：売買手数料だけでなく、為替コスト、信用取引のコスト、口座管理料まで含めた実質負担で比べる。無料コースの適用条件もあわせて確認します。
  • NISAの使い勝手：つみたて投資枠と成長投資枠で、それぞれ何がどこまで買えるか。枠の一部しか使えない構成になっていないか。
  • 最低投資金額：1株から買えるか、積立の下限はいくらか。手元資金と釣り合うか。
  • ツール・アプリとサポート：注文画面の分かりやすさ、情報ツール、問い合わせ手段。取引の頻度が高い人ほど影響が出やすい部分です。

課税口座は複数の証券会社に持てます（一方でNISAは、つみたて投資枠と成長投資枠を別々の金融機関で使うことはできず、同一年は1つの金融機関で利用し、金融機関の変更は年単位で可能とされています）。そのため「投資信託の積立はA社、個別株の売買はB社」といった使い分けをしている人も少なくありません。DMM株のような特化型サービスは、こうした使い分けと相性が良いと考える人もいます。

次の一歩：比べてから決める

一般的な比較手順の一例として、①自分が買いたい商品を1つ決める → ②その商品を扱っている証券会社を3社ほど並べる → ③手数料とNISAでの枠の扱いを確認する、という順番が挙げられます。

株式の売買が中心になりそうな場合は、DMM株を候補に入れるかどうかも含めて、総合型のネット証券と手数料・取扱商品を並べて見比べる形が考えられます。投資信託の積立から始めたい場合は、投資信託の取扱本数や積立の最低金額、クレジットカード積立の有無といった軸で各社を比較するほうが、情報が集まりやすいでしょう。

どの会社が条件に合うかは、資金額・投資対象・売買頻度によって変わります。口座開設の比較情報や各社公式サイトの手数料ページ、初心者向けの投資入門書なども、判断材料として活用してみてください。
