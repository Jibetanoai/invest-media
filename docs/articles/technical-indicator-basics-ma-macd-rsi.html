テクニカル指標の基本｜移動平均線・MACD・RSIの見方を初心者向けに整理

※本記事内には、証券会社や書籍などのサービス紹介にあたりアフィリエイトリンクが含まれる場合があります。

株価やチャートの画面を開いたとき、ローソク足の上に何本もの線が重なっていたり、下のほうに波打つグラフが並んでいたりして、「これ、何を見ればいいの?」と戸惑った経験はないでしょうか。

これらは「テクニカル指標」と呼ばれるもので、過去の値動きを計算して見やすく加工したものです。種類は数十〜数百とありますが、実際のところ、まず押さえておきたいのは移動平均線・MACD・RSIの3つと言われることが多く、多くの証券会社の入門コンテンツでもこの3つが最初に紹介されています。

この記事では、この3つの指標が「何を計算しているのか」「どう見るのか」「どこでハズれやすいのか」を、数式が苦手な方でも追えるように整理します。なお、テクニカル指標は将来の値動きを当てるための道具ではなく、あくまで現状を整理するための"ものさし"です。この前提は最後まで意識しながら読み進めてみてください。

そもそもテクニカル指標とは何か

投資の分析手法は、大きく2つに分けて語られることが多いです。

  • ファンダメンタルズ分析:企業の業績や財務、経済指標、金利などから「本来の価値」を考える
  • テクニカル分析:過去の価格や出来高の推移そのものから、値動きの傾向や勢いを読む

どちらが優れているという話ではなく、見ている対象が違います。長期の資産形成ではファンダメンタルズ寄り、短期の売買ではテクニカル寄りという整理がよくされますが、両方を状況に応じて組み合わせる考え方も一般的です(資産運用EXPO)。

テクニカル指標は、役割でざっくり2種類に分かれます。

種類役割代表例
トレンド系相場の方向と勢いを見る移動平均線、MACD、一目均衡表
オシレーター系買われすぎ・売られすぎの過熱感を見るRSI、ストキャスティクス

この記事で扱う3つは、移動平均線とMACDがトレンド系、RSIがオシレーター系です。性格の違う指標を組み合わせるという発想が、後半の重要なポイントになります。

移動平均線:いちばん基本の「ならした線」

仕組み

移動平均線(MA:Moving Average)は、一定期間の終値の平均値をつないだ線です。たとえば5日移動平均線なら、直近5日間の終値の平均を毎日計算してつないでいきます。

日々の値動きはギザギザしていて方向が分かりにくいのですが、平均をとることで凸凹がならされ、「今どちらを向いているか」が視覚的に分かりやすくなります。テクニカル指標のなかでも古くから使われている、代表的な手法のひとつです(日本テクニカルアナリスト協会)。

よく使われる期間設定は、日足チャートで5日・25日・75日・100日・200日あたり。5日は約1週間、25日は約1カ月、75日は約3カ月の営業日数に対応しています(日本テクニカルアナリスト協会)。週足なら13週・26週・52週などが使われます。

SMAとEMAの違い

移動平均線には主に2種類あります。

  • SMA(単純移動平均):期間内の価格を同じ重みで平均する。素直で分かりやすい
  • EMA(指数平滑移動平均):直近の価格により大きな重みを置く。動きが速く、反応が早い

初心者のうちはSMAで十分と説明されることが多いのですが、後述のMACDはEMAを使って計算されている、という点だけ頭の片隅に置いておくと理解が早くなります(ZAi FX)。

見方の基本3つ

① 線の向きと価格の位置

移動平均線が右肩上がりで、価格がその上にある状態は上昇基調と解釈されます。逆に線が下向きで価格が下にあれば下降基調。まずはこれだけでも、相場の大まかな方向が整理できます。

② ゴールデンクロスとデッドクロス

短期の移動平均線が長期の移動平均線を下から上へ抜けることを「ゴールデンクロス」、上から下へ抜けることを「デッドクロス」と呼びます。前者は買いのサイン、後者は売りのサインとして語られることが多い、最も有名なシグナルです(株の達人)。

ただし注意したいのは、移動平均線は過去の平均を計算したものなので、構造上どうしても値動きに対して遅行性があるということ。クロスが確認できた時点では、すでに相場がある程度動いた後、というケースは珍しくありません。

③ グランビルの法則

米国のJ.E.グランビルが、価格と移動平均線の位置関係から売買タイミングを8つのパターンに整理したものです。買い4パターン・売り4パターンで構成され、移動平均線が広く普及するきっかけになったと言われています(外為オンライン)。すべてを暗記する必要はありませんが、「価格が移動平均線から大きく離れると、いずれ戻りやすい」という発想は覚えておくと応用が利きます。

MACD:移動平均線を発展させた「タイミング寄りの指標」

仕組み

MACD(Moving Average Convergence Divergence、マックディー)は、2本の移動平均線の"差"に注目した指標です。チャートの下に別枠で表示されることが多く、3つの要素で構成されています(OANDA)。

  • MACDライン = 短期EMA − 長期EMA
  • シグナルライン = MACDラインの移動平均(さらにならした線)
  • ヒストグラム = MACDライン − シグナルライン(棒グラフ部分)

期間設定は短期12・長期26・シグナル9が標準的で、多くのツールで初期値になっています。

見方の基本

① 2本の線のクロス

MACDラインがシグナルラインを下から上に抜ければ買いサイン、上から下に抜ければ売りサインとされます。移動平均線のゴールデンクロス/デッドクロスと考え方は同じですが、EMAの差分をベースにしている計算構造上、単純移動平均のクロスよりも反応が早くなりやすいと説明されます(株の達人)。

② ゼロラインとの位置関係

MACDラインがゼロより上にあるとき、短期EMAが長期EMAの上にある=上昇基調。ゼロより下なら下降基調です。ゼロラインをまたぐ動きは、トレンドの転換点として注目されます。

③ ヒストグラムで勢いを見る

ヒストグラムは2本の線の距離です。棒が伸びていれば勢いが強まっており、縮み始めていれば勢いが弱まっているサインと解釈できます。構造上、線が交差する前に縮小が始まるため、「クロスの予兆」として見る使い方も紹介されています。

④ ダイバージェンス(逆行現象)

価格は高値を更新しているのに、MACDは切り下がっている——このような価格と指標のねじれをダイバージェンスと呼びます。上昇の勢いが内部的には弱まっている可能性を示すとされ、弱気のダイバージェンスと言われます。逆に、価格は下落しているのにMACDは切り上がっている場合は強気のダイバージェンスです(フジトミ証券)。

ただしダイバージェンスは、発生してもすぐには反転せず、だらだら続くことがよくあります。単独の根拠として使うのは避けたい部類のシグナルです。

RSI:買われすぎ・売られすぎを測る体温計

仕組み

RSI(Relative Strength Index、相対力指数)は、一定期間の値動きのうち、上昇分がどれくらいの割合を占めたかを0〜100%で表す指標です。期間は14が標準的によく使われます。

計算のイメージはシンプルで、「期間中の値上がり幅の合計 ÷(値上がり幅+値下がり幅の合計)」。全部上昇なら100%、全部下落なら0%に近づきます(外為どっとコム)。

見方の基本

一般的な目安は以下の通りです。

  • 70%以上 … 買われすぎ
  • 30%以下 … 売られすぎ
  • 50%前後 … 中立

なお、よりシビアに見たい場合は、パラメータ14なら75%以上〜25%以下、振れ幅の大きい9なら80%以上〜20%以下を使う、といった調整も紹介されています(株の達人)。値動きの荒い銘柄ではラインを外側に、穏やかな銘柄では内側に寄せる、という調整の考え方もあります。

RSIにも、MACDと同様にダイバージェンス(価格とRSIの逆行)の見方があります。

RSIで初心者がつまずきやすいポイント

RSIは直感的で使いやすい反面、「ダマシ」が起きやすい指標のひとつでもあります。

強いトレンドが出ている相場では、RSIが70〜80%台に張り付いたまま、価格がさらに上がり続けることがあります。「買われすぎだから売り」と判断したのに上昇が止まらず、損失が膨らむ、というのはRSIの典型的な失敗パターンとして各所で注意喚起されています(トレーダーズ・ウェブ)。

こうした背景から、「70に到達した瞬間」ではなく「70超のゾーンからあらためて下に抜けてきた場面」に注目するという見方が紹介されることがあります。到達ではなく折り返しを確認する、というイメージです。これはあくまで解説記事などで紹介されている一例であり、編集部として特定の売買手順を推奨するものではありません。どの水準をどう扱うかは、銘柄の値動きの荒さや自身の投資スタイルによって変わってきます。

3つの指標をどう使い分ける?

ここまでの内容を整理すると、それぞれの得意・不得意が見えてきます。

指標得意なこと苦手なこと
移動平均線大きな方向性の把握反応が遅れやすい。横ばい相場でクロスが乱発
MACDトレンド転換を比較的早めに捉える過熱感は測れない。横ばい相場に弱い
RSI買われすぎ・売られすぎの判定強いトレンド中は機能しにくい

注目したいのは、MACDとRSIが互いの弱点を補い合う関係にあることです。MACDは移動平均線ベースなので過熱感を測れません。一方、RSIは過熱感は測れてもトレンドの方向は分かりません。だからこそ、トレンド系とオシレーター系を組み合わせる使い方が、複数の解説で紹介されています(株の達人)。

たとえば「移動平均線で大きな方向を確認 → MACDでタイミングの目安を取る → RSIで過熱していないか確認する」といった役割分担の例が解説記事などで紹介されています。こうした順番をあらかじめ決めておくと判断がブレにくくなる、という声もありますが、どの組み合わせが合うかは投資スタイルによって異なります。

ただし、指標を増やせば増やすほど精度が上がるわけではありません。5個も6個も表示すると、どれかが「買い」を、どれかが「売り」を示す状態になりやすく、結局は自分の見たいシグナルだけを拾ってしまいがちです。まずは3つ以内から始めるのが現実的でしょう。

テクニカル指標を使う前に知っておきたい3つの前提

① すべての指標は「後追い」である

テクニカル指標は過去の価格データから計算されます。つまり、原理的に未来を先取りすることはできません。「確度の高い予言」ではなく「現状の整理ツール」と捉えるのが健全です。

② 「ダマシ」は一定割合で起きる

シグナル通りに動かないケースは、どの指標にも一定割合で発生します。特に方向感のない横ばい相場(レンジ相場)では、移動平均線もMACDもクロスを繰り返し、機能しにくくなります。「この指標は勝率が高い」といった断定的な情報には、慎重に接したいところです。

③ 長期の積立投資では「出番が少ない」ことも

毎月一定額を投信で積み立てるようなスタイルの場合、テクニカル指標で売買タイミングを細かく計る必要性はそれほど高くありません。金融庁も、長期・積立・分散という考え方を資産形成の基本として紹介しており、短期的な値動きを追いかけるアプローチとは前提が異なります(金融庁「投資の基本」)。

とはいえ、チャートが読めること自体は無駄になりません。相場が急落したときに「今どういう局面なのか」を自分の言葉で整理できると、感情的な判断を避けやすくなる、というメリットもあります。

実際にチャートを触ってみるには

テクニカル指標は、読むより触るほうが理解が進みやすい分野です。移動平均線の期間を25から75に変えてみる、MACDのヒストグラムが縮む場面を過去チャートで探してみる——こうした手作業を何度か繰り返すと、文章では伝わりにくい"感覚"がつかみやすくなります。

チャートを触る環境は、主に次のような選択肢があります。

  • 証券会社の取引ツール・スマホアプリ:口座を持っていれば無料で使えることがほとんど
  • チャート専用のWebサービス:無料プランでも基本的な指標は一通り使える
  • 入門書籍:体系的に学びたい場合。チャートパターン集は手元にあると便利

このうち証券会社のツールは、会社によって搭載しているテクニカル指標の種類数や、スマホアプリでの操作性にかなり差があります。たとえば、標準チャートに同時表示できる指標の数や、対応するテクニカル指標が数十種類に及ぶかどうかといった点は、各社で異なります(株探)。

口座を選ぶときに見ておきたい比較の観点

これから口座を開く方や、チャート環境を見直したい方が確認しておくとよさそうな項目を挙げておきます。特定の1社が全員にとって最適ということはないので、自分の使い方に照らして比べるのが前提です。

  • テクニカル指標の搭載数と種類 … 使いたい指標が入っているか
  • スマホアプリのチャート操作性 … 縦画面でどこまで見られるか、指標の切り替えは簡単か
  • チャートからの発注可否 … チャート画面のまま注文できるか
  • PCツールの有無と条件 … 高機能ツールが無料か、条件付きか
  • 手数料体系 … 取引頻度によって有利不利が変わる
  • NISA(成長投資枠・つみたて投資枠)の対応状況 … 取扱商品数や対象範囲
  • 投資情報・レポートの充実度 … テクニカル分析の解説コンテンツがあるか

チャート機能だけで口座を決める必要はありませんが、テクニカル分析を本格的に学びたいなら、ツールの使いやすさが学習のしやすさに影響したという声は少なくありません。複数社の公式サイトで機能一覧を並べて見比べたり、比較サイトの情報を参考にしたりしながら、自分の優先順位を整理してみてください。

なお、課税口座(総合口座)は複数の証券会社で開設できますが、NISA口座は1人1口座に限られます。金融機関の変更は年単位での手続きとなり、変更したい年にすでにNISA口座で買付をしている場合はその年の変更ができない、といった条件もあります(楽天証券「NISA口座の金融機関変更」)。まずは課税口座でツールを触って比べ、NISA口座をどこに置くかはじっくり検討する、という進め方も考えられます。最新の取扱いは各社・金融庁の公式情報をご確認ください。

まとめ

最後に要点を整理します。

  • 移動平均線は一定期間の終値の平均。方向性の把握に使い、ゴールデンクロス/デッドクロスが代表的なシグナルとして語られることが多い。ただし構造上、反応は遅れやすい
  • MACDは2本のEMAの差に注目した指標。線のクロス・ゼロライン・ヒストグラム・ダイバージェンスの4つの見方がある。計算構造上、単純移動平均のクロスより反応が早くなりやすいとされる
  • RSIは上昇の勢いを0〜100%で表す。70%以上/30%以下が目安だが、強いトレンド中は張り付くため、到達ではなく「折り返し」を見る考え方も紹介されている
  • 3つは役割が違うので、トレンド系+オシレーター系の組み合わせで弱点を補い合う使い方が基本とされる
  • どの指標も過去データの加工物であり、ダマシは一定割合で起きる。断定的な判断材料としては扱わない

まずは、自分が気になっている銘柄や指数のチャートに移動平均線を1本だけ表示してみるところから始めてみてはいかがでしょうか。そこからMACD、RSIと1つずつ足していくほうが、最初から全部載せるより身につきやすいのではないでしょうか。
