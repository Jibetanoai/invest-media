積立投資と一括投資、どっちがいい？ドルコスト平均法の考え方を初心者向けに整理

※本記事には、商品・サービスの紹介に際してアフィリエイトリンクが含まれる場合があります。

「まとまったお金があるけれど、一気に投じるべきか、毎月に分けるべきか」——これは投資を始めた多くの人が一度はぶつかる悩みです。ネット上には「一括のほうが有利」という意見と「ドルコスト平均法こそ王道」という意見が混在していて、どちらも一理あるように見えます。

先に整理しておくと、この問いに「誰にとっても正しい唯一の答え」はありません。ただし、過去データが示す傾向と、自分の資金や心理に照らした判断軸を知っておけば、検討の材料は増えます。この記事では、その両方を整理していきます。

そもそもドルコスト平均法とは何か

ドルコスト平均法とは、毎月1万円のように「一定の金額」を「定期的に」同じ対象に投じ続ける買い方のことです。ポイントは「一定の口数」ではなく「一定の金額」である点にあります。

  • 価格が高いとき → 買える口数は少なくなる
  • 価格が安いとき → 買える口数は多くなる

この結果、平均購入単価が自動的にならされていきます。感情に左右されず「安いときに多く買う」動きが仕組みとして組み込まれるのが、この手法の特徴とされています。

なお、投資信託の値段は「基準価額」と呼ばれ、1万口あたりの価格として毎営業日1回算出されます。「口数」は保有している量の単位だと考えてください。

よくある誤解:「単価が下がる=得をする」ではない

ドルコスト平均法は、あくまで購入単価をならす手法であって、利益を生み出す装置ではありません。買った対象そのものが長期的に値下がりし続けた場合、平均単価が下がっても評価額は増えないことがあります。「買い方」より先に「何を買うか」「どれだけの期間持つか」が効いてくる、という順序は押さえておきたいところです。

過去データでは一括が上回った局面が多い——ただし条件付き

意外に思われるかもしれませんが、リターンの平均値という一点だけで比べると、過去データでは一括投資のほうが上回った局面が多かったというのが、複数の検証に共通する報告です。

資産運用会社バンガードが公表している分析では、1976年〜2022年の米国市場データを用い、株式60%・債券40%のバランス型ポートフォリオで「一括投資」と「12か月かけて分割投資」を比較したところ、一括投資が上回ったケースがおよそ68%、平均的な差は約2.3ポイントだったと報告されています。

理由として挙げられるのは、投資を待機している現金が、その間の値動きに参加できない点です（機会損失と呼ばれます）。実際、S&P500の暦年トータルリターンは、1926年以降で見るとおおむね7割強の年がプラスだったとされています。もっとも、これは特定の指数・特定の期間の実績にすぎず、今後も同じ傾向が続くことを示すものではありません。

日本でも、全世界株式指数などを使った同種のシミュレーションで、同じ総額・同じ期間なら一括投資のほうが最終評価額が大きくなりやすい、という結果が紹介されています。

「平均的に有利」と「あなたにとって最適」は別

ここで立ち止まりたいのが、「約68%で上回った」という数字は、裏を返せば約3割では下回ったということです。しかも下回るパターンは、投資直後に大きく下落したケース、つまり精神的にこたえる形で訪れやすいものです。

投資は期待値の計算だけで完結しません。含み損に耐えられずに底値で売ってしまえば、統計上の優位性は失われます。続けられるかどうかは、期待リターンと同じくらい重要な要素だと指摘されることが多く、投資を始めたばかりの人ほど意識しておきたい視点です。

積立が語られやすい場面、一括が語られやすい場面

どちらが合うかは、突き詰めると「資金の性格」と「リスク許容度」に左右されます。リスク許容度とは、値下がりにどこまで耐えられるかの度合いで、資産額・年齢・収入の安定性・性格などによって変わるとされます。

一般的には、次のような整理が紹介されています。

積立が語られやすいケース

  • 毎月の給与から捻出するため、そもそもまとまった資金がなく一括という選択肢が存在しない
  • 相場の下落が気になって落ち着かないタイプだと自覚している
  • 投資を始めたばかりで、自分がどのくらいの下落に耐えられるか未知数
  • 資金を使う時期がまだ遠い（20年以上先など）

一括が語られやすいケース

  • 退職金・相続・ボーナスなどで、すでに現金として手元にある
  • 過去に下落局面を経験し、自分の耐性をある程度把握している
  • 生活防衛資金（一般に生活費の3か月〜1年分程度が目安とされます）が別途確保されている

いずれも一般論であり、どの条件に当てはまれば正解、という性質のものではありません。最終的にどうするかは、ご自身の状況に照らして判断することになります。

中間的な考え方:「時間分散を短めに区切る」

「全額一括は不安だが、何年もかけて分けるのは長すぎる気がする」という場合について、半年〜2年程度で計画的に投じ切るという中間案が紹介されることもあります。前掲のバンガードの検証も12か月での分割を比較対象としており、分割期間を短く区切る発想はこの流れに沿ったものです。期待値の取りこぼしを抑えつつ、高値づかみ一発のダメージを和らげる、という位置づけで説明されます。

どの方法を採るにせよ、あらかじめルールを決めて機械的に実行することが重要だとよく言われます。「もう少し下がったら買おう」と裁量で待つ形にすると、判断が先送りされやすいことが行動経済学の文脈でも指摘されています。

「今は高値だから待つ」は有効なのか

高値警戒論は、相場が上がるたびに繰り返し聞かれます。ここ数年の日本株を振り返ると、その難しさがよく分かります。

2025年の日経平均株価は、11月に5万2,600円台まで水準を切り上げ、大納会の終値は5万0,339円と史上初めて5万円台で年を越しました。前年末比では+26.2%、上昇幅は過去最大で、3年連続の上昇となっています。当時も「さすがに高すぎる」という声は少なくありませんでした。

その後の2026年も上昇基調が続き、9月上旬時点の日経平均は6万4,000〜6万6,000円台で推移しています。証券会社の中には2026年末予想を7万円へ引き上げたところもある一方、中東情勢やインフレ動向を材料に調整局面が生じる場面もあり、見方は分かれています。

つまり、高値圏に見えるかどうかは事後的にしか判定できません。最高値の更新後にさらに上昇が続いた実例もあれば、そこから調整に入った実例もあります。プロの予想でも一致しないものを、個人が売買タイミングとして当て続けるのは現実的ではありません。 だからこそ、タイミング判断を前提としない積立という仕組みに一定の合理性がある、というのが一般的な整理です。

見落とされがちな「出口」の話

積立投資の議論は「買い方」に偏りがちですが、取り崩し方も結果に影響します。

長期の積立で資産が育つほど、後半の1年間の値動き額は、初期の数年分の積立額を上回ることもあります。つまり時間が経つほど、積立による平準化効果は相対的に薄まり、資産全体が相場変動にさらされる状態に近づいていきます。

そのため、使う時期が近づいた局面については、一般的な考え方として次のような選択肢が挙げられます。

  • 株式の比率を段階的に下げていく方法
  • 一度に全額を売らず、数年かけて分割で取り崩す方法
  • 使う予定が明確な資金を、早めに現金・預金へ移しておく方法

いずれも唯一の正解というわけではなく、目的や時期によって適否は変わります。入口で時間分散を意識するなら、出口でも同じ発想を持っておくと、検討の視野が広がります。

制度面の前提:NISAの枠と積立の相性

日本では2024年に始まった新NISAの利用が広がっており、金融庁の公表資料によると、2025年12月末時点でNISA口座数は約2,821万口座、買付額は累計で約71.4兆円（前年比で大幅増）に達しています。

制度の設計上、押さえておきたいのは以下の点です。

項目つみたて投資枠成長投資枠
年間投資枠120万円240万円
買い方積立のみ一括・積立どちらも可
対象商品一定の条件を満たす投資信託等上場株式・投資信託等（一部除外）

つまり「一括で投じたい」場合は成長投資枠を使うことになり、年間で投じられる額には上限があります。まとまった資金があっても、非課税で運用できる枠には制度上の制約があるため、何年かけて枠を埋めるかという計画自体が、実質的に時間分散の設計になります。一括か積立かの二択で考えるより、実務的な論点になりやすい部分です。

実行段階で効いてくる「証券会社の設定の違い」

方針が決まったら、次は実行環境です。同じ「毎月積立」でも、金融機関によって使える設定はかなり異なります。特定の1社が万能ということはなく、自分のやりたい買い方が実現できるかという視点で見比べるのが現実的です。

比較しておきたい主な観点は次のとおりです。

  • 積立頻度：毎月のみか、毎週・毎日も選べるか
  • 最低積立額：100円単位か、1,000円単位か
  • ボーナス設定：特定月だけ増額する設定ができるか（一括と積立の中間を作りやすい）
  • クレジットカード積立：対応の有無、上限額、還元の条件
  • 成長投資枠での積立設定：枠をまたいだ自動化ができるか
  • 取扱商品の本数：低コストのインデックスファンドが揃っているか
  • アプリ・管理画面：設定変更や積立停止が簡単にできるか

「毎日積立にしたいのに月1回しか選べない」「ボーナス月だけ増額したいのに設定がない」といったミスマッチは、口座を開いた後で気づくと変更に手間がかかります。先に自分の方針を決め、それが実現できる口座を選ぶという順番のほうが、後戻りは少なくなります。

なお、NISA口座は1人1口座が原則で、同一年に複数の金融機関で開設することはできません（金融機関の変更は年単位で可能です）。焦って決める必要はありませんが、複数社の条件を並べて比べておくと判断しやすくなります。

また、手数料体系やポイント還元の条件は改定が頻繁なため、本記事では各社の具体的な還元率・数値には踏み込みません。検討の際は、必ず各社の最新の公式情報をご確認ください。

まとめ:優劣ではなく「相性」で考える

  • 期待リターンの平均値だけで比べると、過去データでは一括投資が上回った局面が多かったという報告がある
  • ただし一括は、投資直後の下落を全額で受け止めるため、続けられなくなるリスクを抱える
  • ドルコスト平均法は「儲けるための手法」ではなく、単価をならし、判断の負担を減らす仕組み
  • 手元資金の性格・使う時期・下落への耐性によって、適した方法は変わる
  • 「半年〜2年で分割して投じ切る」といった中間的な考え方も紹介されている
  • 入口だけでなく、出口(取り崩し)の時間分散も併せて考えたい

どちらの方法を選ぶにせよ、成果が保証されるものではありません。相場環境によっては元本を下回る可能性もあります。だからこそ、他人の正解を探すよりも、自分が10年、20年と続けられる形を先に決めておくほうが、納得して続けやすくなるはずです。

検討の材料として、①生活防衛資金がいくら必要かを計算しておく、②投じる資金の使用時期を書き出しておく、③その方針に合う積立設定ができる金融機関の条件を並べてみる——といった整理をしておくと、比較しやすくなります。投資の入門書やNISA制度の公的な解説資料にも一度目を通しておくと、判断の土台が固まります。
